# EV-BMS-Power-Management

## Project Overview
This project presents a MATLAB/Simulink implementation of a Power Management Strategy for a Battery Management System (BMS) used in Electric Vehicles.

## Features
- Battery State of Charge (SOC) Estimation
- Battery State of Health (SOH) Estimation
- Cell Balancing
- Charging and Discharging Characteristics
- Battery Protection
- Maximum Charge and Discharge Power Estimation
- Battery Temperature and Current Monitoring

## Software Used
- MATLAB R2025b
- Simulink
- Simscape

## Project Outputs
- SOC Estimation Results
- SOH Estimation Results
- Battery Protection Model
- Cell Balancing Model
- Charging/Discharging Characteristics

## Future Work
- AI-based SOC Prediction
- Thermal Management
